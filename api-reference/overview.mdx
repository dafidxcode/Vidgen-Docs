Vigen API punya lima endpoint. Semuanya memakai origin yang sama, autentikasi yang sama, dan bentuk error yang sama.

| Method | Path | Auth | Balas |
| --- | --- | --- | --- |
| `POST` | [`/api/v1/generate`](/api-reference/generate) | API key | `202` job baru, `200` replay idempoten |
| `GET` | [`/api/v1/jobs/{id}`](/api-reference/get-job) | API key | `200` |
| `POST` | [`/api/v1/upload`](/api-reference/upload) | API key | `200` objek aset |
| `GET` | [`/api/v1/models`](/api-reference/models) | publik | `200` |
| `GET` | [`/api/v1/user/credits`](/api-reference/credits) | API key | `200` |

## Konvensi

- **Base URL** `https://vigen.id`, prefix path `/api/v1`. Lihat [Base URL](/api-base-url).
- **Autentikasi** lewat `Authorization: Bearer vg_...` **atau** `x-api-key: vg_...`. Lihat [Autentikasi](/authentication).
- **Content type** `application/json; charset=utf-8`, kecuali upload yang memakai `multipart/form-data`.
- **Waktu** memakai ISO-8601 UTC (`2026-11-04T09:12:44.000Z`). Kuota harian dihitung dalam WIB.
- **Body sukses** selalu memuat `"success": true` di samping datanya.
- **Tanpa CORS**: panggil dari server, bukan dari browser.

## Bentuk error

Setiap kegagalan memakai body ini:

```json theme={null}
{ "error": "Pesan yang layak dibaca manusia." }
```

Yang membedakan adalah status HTTP. Beberapa error menambahkan field diagnostik:

| Status | Makna | Field tambahan |
| --- | --- | --- |
| `400` | Permintaan tidak bisa dipahami atau ditolak validasi | `fields` (saat parameter bermasalah) |
| `401` | Key tidak ada, salah format, atau dicabut | — |
| `402` | Kredit tidak cukup | `requiredCredits`, `currentCredits` |
| `403` | Job bukan milik akun ini | — |
| `409` | Model ada tapi sedang tidak aktif | — |
| `413` | Berkas melebihi 100 MB | — |
| `429` | Batas konkurensi, kuota harian, antrean penuh, atau batas unggah | `maxConcurrent`, `activeJobs`, `dailyVideosUsed`, `resetsAt`; header `Retry-After` di upload |
| `500` | Kegagalan di sisi Vigen saat memuat data | — |
| `503` | Pemeliharaan, layanan sesi/kredit tidak bisa diakses | — |

<Info>
  Vigen tidak mengeluarkan kode error numerik sendiri. Jangan mem-parse string untuk logika — pakai status HTTP, lalu baca field diagnostik bila ada.
</Info>

## Pesan error tidak pernah berisi detail internal

Jalur keluar ke pengguna sudah disaring: nama penyedia, URL internal, dan respons mentah dari sistem hulu tidak akan muncul di `error` maupun `errorMessage`. Yang kamu dapat adalah kalimat yang bisa langsung diteruskan ke pengguna akhir. Kalau ada yang janggal, laporkan `job.id` beserta statusnya.
