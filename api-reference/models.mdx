Mengembalikan model yang sedang bisa dipakai, dikelompokkan ke `video`, `image`, dan `audio`. Model yang dinonaktifkan tidak muncul.

<Info>
  Endpoint ini **tidak memerlukan API key** karena isinya katalog publik. Halaman-halaman lain di tab ini tetap butuh key.
</Info>

<RequestExample>

```bash cURL theme={null}
curl https://vidgen.id/api/v1/models
```

```js Node.js theme={null}
const models = await (await fetch("https://vidgen.id/api/v1/models")).json();

const video = models.models.video.find((m) => m.capabilities.durations.includes("30"));
console.log(video?.id, video?.creditsDefault, video?.priceMatrix);
```

```python Python theme={null}
models = requests.get("https://vidgen.id/api/v1/models").json()["models"]

for m in models["video"]:
    print(m["id"], m["capabilities"]["durations"], m["creditsDefault"])
```

</RequestExample>

### Responses

<ResponseField name="success" type="boolean" required>
  `true` saat katalog berhasil dimuat.
</ResponseField>

<ResponseField name="models" type="object" required>
  Tiga keranjang: `video`, `image`, `audio`. Tiap-tiapnya array objek model.

  <Expandable title="satu entri model" defaultOpen>
    <ResponseField name="id" type="string" required>
      Nilai untuk field `model` saat generate.
    </ResponseField>
    <ResponseField name="label" type="string">
      Nama tampilan. Bisa berubah; jangan dijadikan kunci logika.
    </ResponseField>
    <ResponseField name="category" type="string">
      `"Video"`, `"Image"`, atau `"Audio"`.
    </ResponseField>
    <ResponseField name="mode" type="string">
      `video`, `image`, atau `audio`.
    </ResponseField>
    <ResponseField name="creditsDefault" type="number" required>
      Harga dasar dalam kredit bila tidak ada override yang cocok. Bisa pecahan.
    </ResponseField>
    <ResponseField name="unlimitedOnly" type="boolean" required>
      `true` bila model hanya tersedia untuk pemilik paket Unlimited aktif. Memanggilnya tanpa langganan dijawab `403`, bukan `402`. Jangan menyaring model langganan dari `creditsDefault === 0` — pakai flag ini.
    </ResponseField>
    <ResponseField name="priceMatrix" type="object">
      Override harga. Kunci yang mungkin: durasi (`"15"`), resolusi (`"720p"`), kombinasi (`"720p:15"`), atau kualitas:resolusi (`"low:2K"`).
    </ResponseField>
    <ResponseField name="capabilities" type="object">
      Aturan validasi parameter untuk model ini.

      <Expandable title="isi capabilities">
        <ResponseField name="durations" type="array<string>">
          Nilai valid untuk `parameters.duration`.
        </ResponseField>
        <ResponseField name="ratios" type="array<string>">
          Nilai valid untuk `parameters.ratio`. `auto` selalu diterima dan tidak divalidasi.
        </ResponseField>
        <ResponseField name="resolutions" type="array<string>">
          Nilai valid untuk `parameters.resolution`.
        </ResponseField>
        <ResponseField name="maxReferenceImages" type="number">
          Batas gambar referensi.
        </ResponseField>
        <ResponseField name="maxReferenceVideos" type="number">
          Batas video referensi.
        </ResponseField>
        <ResponseField name="maxReferenceAudios" type="number">
          Batas audio referensi.
        </ResponseField>
        <ResponseField name="minReferenceVideos" type="number">
          Jumlah video referensi minimum. Hanya muncul bila lebih dari 0; permintaan tanpa video dijawab `400` sebelum kredit terpotong.
        </ResponseField>
        <ResponseField name="qualities" type="array<string>">
          Nilai valid untuk `parameters.quality`. Hanya muncul pada model yang mendukungnya, dan ikut menentukan harga lewat kunci `quality:resolution`.
        </ResponseField>
        <ResponseField name="backgrounds" type="array<string>">
          Nilai valid untuk `parameters.background`, misal `auto`, `opaque`, `transparent`.
        </ResponseField>
        <ResponseField name="outputFormats" type="array<string>">
          Nilai valid untuk `parameters.output_format`, misal `png`, `jpeg`, `webp`.
        </ResponseField>
        <ResponseField name="supportsNegativePrompt" type="boolean">
          Hanya muncul bila `true`. Artinya `parameters.negative_prompt` diteruskan ke generator.
        </ResponseField>
        <ResponseField name="supportsSeed" type="boolean">
          Hanya muncul bila `true`. Artinya `parameters.seed` diteruskan ke generator.
        </ResponseField>
        <ResponseField name="feature" type="string">
          `"create"` atau `"motion"`. Model `motion` mengambil durasi dari video referensi dan mengabaikan `parameters.duration`.
        </ResponseField>
        <ResponseField name="motion" type="object">
          Hanya pada model motion: `minDurationSec`, `maxDurationSec`, dan kadang `durationFromReference`.
        </ResponseField>
        <ResponseField name="modes" type="array<string>">
          Khusus audio: pola penulisan lagu, misal `custom`, `simple`, `cover`.
        </ResponseField>
        <ResponseField name="versions" type="array<string>">
          Khusus audio: versi mesin yang bisa dipilih.
        </ResponseField>
      </Expandable>

      Kunci opsional hanya diterbitkan saat modelnya memang punya. Kunci yang tidak ada berarti parameter itu diabaikan server — tidak error, tidak berpengaruh.
    </ResponseField>
  </Expandable>
</ResponseField>

## Cara memakainya di produk

<AccordionGroup>
  <Accordion title="Cache, jangan hardcode">
    Ambil katalog sekali saat layananmu start, simpan 5–15 menit, dan segarkan saat menerima `409` (`model ... sedang tidak tersedia`). Daftar model berubah tanpa pengumuman.
  </Accordion>
  <Accordion title="Bangun UI dari capabilities">
    Sembunyikan pilihan yang tidak ada di capabilities model terpilih: `durations`, `ratios`, `resolutions`, lalu `qualities`, `backgrounds`, dan `outputFormats` bila kunci itu ada. Untuk referensi, tampilkan uploader gambar hanya bila `maxReferenceImages > 0`, dan seterusnya untuk video dan audio. Validasi di sisi kamu sebelum mengirim memangkas permintaan yang pasti ditolak server.
  </Accordion>
  <Accordion title="Hitung perkiraan biaya">
    Tirukan urutan pencarian harga server: `quality:resolution` → `resolution:duration` → `duration` → `resolution` → `creditsDefault`. Beberapa model hanya mengisi sebagian kombinasi (matriks jarang); kunci yang tidak ada jatuh ke tingkat berikutnya, bukan ke error. Referensi belum menambah biaya.
  </Accordion>
  <Accordion title="Model Unlimited bukan model gratis">
    `unlimitedOnly: true` berarti model itu hanya untuk pemilik paket Unlimited aktif. `creditsDefault`-nya `0` karena tagihannya masuk kuota, bukan karena gratis untuk semua akun. Tanpa langganan, `POST /api/v1/generate` menjawab `403` dengan `code: "unlimited_required"` sebelum kredit tersentuh. Untuk menampilkan pilihan yang benar ke pengguna biasa, saring `models.video.filter((m) => !m.unlimitedOnly)`.
  </Accordion>
  <Accordion title="Gemini Omni 1.1 dan 1.2 berbeda jalur">
    Keduanya Unlimited, tapi kemampuannya tidak sama: `gemini-omni-1.1-unlimited` menerima sampai 3 gambar dan tanpa video, `gemini-omni-1.2-unlimited` menerima 1 gambar + 1 video (ref-to-video) dan durasi `5` atau `10`. Jangan menyamakan UI keduanya — baca `maxReferenceVideos` dan `durations` masing-masing. Antreannya juga berbeda: lihat [Konkurensi & batas pemakaian](/concepts/concurrency-limits).
  </Accordion>
  <Accordion title="Audio muncul di katalog, tapi belum bisa digenerate">
    Keranjang `audio` diisi `suno-v6` dan `suno-cover-v6`. Pengirimannya melalui API key belum dibuka, jadi tampilkan sebagai "hanya di dashboard". Kunci `modes` dan `versions` diterbitkan untuk kesiapan integrasi, bukan tanda endpoint sudah aktif.
  </Accordion>
</AccordionGroup>
