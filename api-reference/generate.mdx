Membuat satu job generate. Kredit dipotong pada endpoint ini, dan request dijawab **sebelum** hasilnya jadi.

<Info>
  Butuh daftar model yang bisa diisi di field `model`? Ambil dari [`GET /api/v1/models`](/api-reference/models). Nilai `parameters` yang valid juga bergantung pada model.
</Info>

### Authorizations

<ParamField path="Authorization" type="string" required>
  API key berformat `Bearer vg_...`. Bisa juga memakai header `x-api-key`.
</ParamField>

### Request body

<ParamField body="model" type="string" required>
  Id model dari katalog, misalnya `muse-video`. Ejaan dengan titik dan tanda hubung diperlakukan sama. Model yang ada tapi sedang dinonaktifkan dijawab `409`. Batas referensi berbeda tiap model; baca `capabilities` dari katalog sebelum mengirim `references`.
</ParamField>

<ParamField body="prompt" type="string">
  Deskripsi yang ingin dibuat. **Wajib** kecuali untuk model motion control, yang boleh kosong karena server mengisi instruksi netral. Maksimal 2.500 karakter untuk model motion.

  Prompt melewati penyaringan konten lebih dulu; kata sensitif, tokoh publik, atau indikasi pelanggaran dihapus sebelum diteruskan. Sebagian model yang secara terbuka dijual tanpa penyaringan dikenali dari id-nya (`spicy`, `nsfw`) dan tidak disaring.
</ParamField>

<ParamField body="parameters" type="object" default="{}">
  Pengaturan keluaran. Hanya kunci yang dikenal yang diproses; kunci lain diabaikan tanpa error.

  <Expandable title="sifat yang dikenali">
    <ParamField body="duration" type="string">
      Durasi dalam detik, misal `"5"` atau `"30"`. Akhiran `s` diterima dan dibuang. Divalidasi terhadap `capabilities.durations`. **Diabaikan pada model motion control.** Bila dilewat, server memakai entri pertama `capabilities.durations` — dan harga dihitung dari nilai itu, bukan dari `creditsDefault`.
    </ParamField>
    <ParamField body="resolution" type="string">
      Resolusi, misal `"720p"`, `"1080p"`, `"1K"`, `"2K"`, `"4K"`. Divalidasi terhadap `capabilities.resolutions`. Bila dilewat, server memakai entri pertama daftar itu.
    </ParamField>
    <ParamField body="ratio" type="string">
      Rasio aspek: `"16:9"`, `"9:16"`, `"1:1"`, `"4:3"`, `"3:4"`, atau `"auto"`. `aspect_ratio` diterima sebagai alias.
    </ParamField>
    <ParamField body="quality" type="string">
      Untuk model gambar yang punya `capabilities.qualities` (`low`, `medium`, `high`, `xhigh`, `max`). Ikut menentukan harga lewat kunci `quality:resolution`. Diabaikan bila model tidak mendukung.
    </ParamField>
    <ParamField body="background" type="string">
      Untuk model gambar yang punya `capabilities.backgrounds` (`auto`, `transparent`, `opaque`).
    </ParamField>
    <ParamField body="output_format" type="string">
      Format keluaran; `format` diterima sebagai alias. Hanya dipakai jika model punya `capabilities.outputFormats`.
    </ParamField>
    <ParamField body="negative_prompt" type="string">
      Hal yang tidak diinginkan. Hanya diteruskan jika `capabilities.supportsNegativePrompt`.
    </ParamField>
    <ParamField body="seed" type="string">
      Biji acak untuk hasil yang bisa diulang. Hanya diteruskan jika `capabilities.supportsSeed`.
    </ParamField>
    <ParamField body="orientation" type="string">
      Khusus motion control: `"image"` (rasio mengikuti gambar karakter) atau `"video"` (rasio mengikuti video gerakan). Nilai lain diabaikan.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="references" type="array<object>">
  Bahan masukan: gambar karakter, produk, atau video gerakan. Tiap objek bisa berupa aset hasil [`POST /api/v1/upload`](/api-reference/upload) **atau** URL publik.

  <Expandable title="objek referensi">
    <ParamField body="id" type="string">
      Id aset dari endpoint upload. Kalau ada, objek ini dipakai apa adanya (kirim juga `url`, `file_url`, dan `filename` seperti yang kamu terima).
    </ParamField>
    <ParamField body="url" type="string">
      URL media publik (`http` atau `https`) yang akan diunduh server dengan timeout 20 detik. Kegagalan unduhan dijawab `400`.
    </ParamField>
    <ParamField body="type" type="string">
      `"image"`, `"video"`, atau `"audio"`. Boleh dilewat — server mendeteksi dari isi berkas. Jumlah maksimum bergantung model dan dibaca dari `capabilities.maxReferenceImages`, `maxReferenceVideos`, dan `maxReferenceAudios`. Nilai `0` berarti model itu menolak jenis referensi tersebut.
    </ParamField>
    <ParamField body="filename" type="string">
      Nama berkas di penyimpanan server. Ikuti persis nilai dari respons upload.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="idempotencyKey" type="string">
  Minimal 8 karakter. Key yang sama mengembalikan job yang sudah ada dengan `200` dan `idempotent: true`, tanpa potongan kredit kedua. Di bawah 8 karakter, nilai kamu diabaikan dan server membuat key sendiri. Lihat [Idempotensi](/concepts/idempotency).
</ParamField>

### Responses

<ResponseField name="success" type="boolean">
  `true` pada semua respons sukses.
</ResponseField>

<ResponseField name="job" type="object" required>
  Objek job.

  <Expandable title="sifat job" defaultOpen>
    <ResponseField name="id" type="string" required>
      Id untuk polling di `GET /api/v1/jobs/{id}`.
    </ResponseField>
    <ResponseField name="status" type="string" required>
      `"queued"` untuk job baru. Nilai lain: `dispatching`, `processing`, `succeeded`, `failed`, `cancelled`.
    </ResponseField>
    <ResponseField name="model" type="string">
      Id model yang dipakai.
    </ResponseField>
    <ResponseField name="category" type="string">
      `"Video"`, `"Image"`, atau `"Audio"`.
    </ResponseField>
    <ResponseField name="prompt" type="string">
      Prompt **setelah** penyaringan konten. Ini yang benar-benar diproses.
    </ResponseField>
    <ResponseField name="creditsCharged" type="number" required>
      Kredit yang dipotong. `0` bila kuota Unlimited terpakai.
    </ResponseField>
    <ResponseField name="createdAt" type="string (ISO 8601)">
      Waktu job dibuat, UTC.
    </ResponseField>
    <ResponseField name="result" type="object | null">
      Hanya terisi pada respons idempoten untuk job yang sudah selesai; untuk job baru selalu `null`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="queue" type="object">
  Informasi antrean saat request dibuat.

  <Expandable title="isi queue">
    <ResponseField name="position" type="number">
      Posisi di antrean. `0` berarti sedang diproses atau posisinya tidak dilaporkan.
    </ResponseField>
    <ResponseField name="status" type="string">
      Mengikuti status job, umumnya `"queued"`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="idempotent" type="boolean">
  Hanya muncul saat key yang sama sudah pernah dipakai dan job lama dikembalikan.
</ResponseField>

## Yang perlu kamu tahu

<AccordionGroup>
  <Accordion title="Kenapa 202, bukan 200?">
    Generate bersifat asinkron. `202` berarti permintaan diterima dan antrean sudah disiapkan; hasilnya diambil nanti lewat job id. Satu-satunya `200` di endpoint ini adalah replay idempoten.
  </Accordion>
  <Accordion title="Kapan kredit dipotong dan kapan kembali?">
    Dipotong sebelum job disimpan. Kalau job gagal, batal tersimpan, atau antrean penuh, kredit dikembalikan otomatis dengan reason refund yang tercatat di riwayat akun. Kamu tidak perlu membuat mekanisme refund sendiri.
  </Accordion>
  <Accordion title="Apakah request bisa diulang dengan aman?">
    Ya, asal memakai `idempotencyKey` yang sama dan panjangnya minimal 8 karakter. Tanpa itu, setiap retry adalah job baru dengan tagihan baru.
  </Accordion>
  <Accordion title="Field tambahan pada body diabaikan?">
    Ya. Body yang mengirim `watermark: false` atau `n: 2` tidak error, tapi juga tidak berefek. Hanya `model`, `prompt`, `parameters`, `references`, `idempotencyKey` yang dibaca.
  </Accordion>
  <Accordion title="Batas yang membuat request ini ditolak">
    Dua proses bersamaan (khusus akun Unlimited), 50 video sukses per hari, antrean server penuh, atau situs sedang pemeliharaan. Semuanya memakai `429` atau `503`.
  </Accordion>
  <Accordion title="Model Unlimited dan kode 403">
    Model dengan `unlimitedOnly: true` di katalog hanya bisa dipakai akun yang paket Unlimited-nya aktif. Tanpa langganan, endpoint ini menjawab `403` dengan `code: "unlimited_required"` dan `model` berisi id yang diminta. Kredit tidak terpotong. Jangan menyamakan `403` ini dengan `403` di `GET /api/v1/jobs/{id}` (job milik akun lain) — bedakan lewat `code`.
  </Accordion>
  <Accordion title="Nilai bawaan duration dan resolution">
    Bila kamu tidak mengirim `duration` atau `resolution`, server memakai entri pertama daftar di `capabilities` model itu, dan harga dihitung dari nilai tersebut. Kirim eksplisit kalau kamu butuh kombinasi tertentu — terutama pada model video, karena durasi adalah pengali biaya utama.
  </Accordion>
</AccordionGroup>
