Model Vidgen dikelola dari server dan bisa berubah kapan saja — model baru masuk, model lama dipensiunkan, harga kredit disesuaikan. Karena itu **jangan hardcode daftar model** di produkmu. Ambil dari runtime:

```bash theme={null}
curl https://vidgen.id/api/v1/models
```

Endpoint ini publik (tanpa API key) dan mengembalikan tiga keranjang: `video`, `image`, `audio`. Hanya model aktif yang muncul.

Halaman ini adalah referensi lengkap per model per **8 November 2026**. Angkanya berguna untuk membangun UI dan memperkirakan biaya, tetapi `GET /api/v1/models` tetap satu-satunya sumber kebenaran saat kode kamu berjalan.

## Bentuk satu entri

```json theme={null}
{
  "id": "gpt-image-2.6-sunburst",
  "label": "GPT Image 2.6 Sunburst",
  "category": "Image",
  "mode": "image",
  "creditsDefault": 1,
  "unlimitedOnly": false,
  "priceMatrix": {
    "1K": 2, "2K": 3, "4K": 5,
    "low:1K": 1, "low:2K": 2, "low:4K": 3,
    "medium:1K": 2, "medium:2K": 3, "medium:4K": 5,
    "high:1K": 2, "high:2K": 4, "high:4K": 6,
    "xhigh:1K": 3, "xhigh:2K": 6, "xhigh:4K": 10,
    "max:1K": 7, "max:2K": 13, "max:4K": 21
  },
  "capabilities": {
    "durations": [],
    "ratios": ["1:1", "2:3", "3:2", "3:4", "4:3", "4:5", "5:4", "9:16", "16:9", "21:9"],
    "resolutions": ["1K", "2K", "4K"],
    "qualities": ["low", "medium", "high", "xhigh", "max"],
    "backgrounds": ["auto", "opaque", "transparent"],
    "outputFormats": ["png", "jpeg", "webp"],
    "maxReferenceImages": 16,
    "maxReferenceVideos": 0,
    "maxReferenceAudios": 0
  }
}
```

| Field | Arti |
| --- | --- |
| `id` | Nilai yang kamu kirim di body `model`. |
| `label` | Nama tampilan. Bisa berubah; jangan jadikan kunci logika. |
| `category` | `Video` \| `Image` \| `Audio`. |
| `mode` | Sama dengan `category` tapi huruf kecil; dipakai untuk memilih tab parameter. |
| `creditsDefault` | Harga dasar dalam kredit bila tidak ada override yang cocok. |
| `unlimitedOnly` | `true` bila model hanya bisa dipakai pemilik paket Unlimited aktif. Tanpa langganan, request dijawab `403`. |
| `priceMatrix` | Override per kunci: `"15"`, `"720p"`, `"720p:15"`, atau `"low:2K"` (kualitas:resolusi). |
| `capabilities.durations` | Nilai valid untuk `parameters.duration`. |
| `capabilities.ratios` | Nilai valid untuk `parameters.ratio`. `auto` selalu diterima dan tidak divalidasi. |
| `capabilities.resolutions` | Nilai valid untuk `parameters.resolution`. |
| `capabilities.qualities` | Nilai valid untuk `parameters.quality`. Hanya ada pada model gambar tertentu. |
| `capabilities.backgrounds` | Nilai valid untuk `parameters.background`. |
| `capabilities.outputFormats` | Nilai valid untuk `parameters.output_format`. |
| `capabilities.supportsNegativePrompt` | Bila `true`, `parameters.negative_prompt` diteruskan. |
| `capabilities.supportsSeed` | Bila `true`, `parameters.seed` diteruskan. |
| `capabilities.maxReferenceImages` / `Videos` / `Audios` | Berapa banyak referensi jenis itu yang boleh dikirim. |
| `capabilities.minReferenceVideos` | Jumlah video referensi MINIMUM. Kalau ada, permintaan tanpa video dijawab `400` sebelum kredit terpotong. |
| `capabilities.feature` | `"create"` atau `"motion"`. Model `motion` punya aturan durasi sendiri. |
| `capabilities.motion` | Rentang durasi referensi (`minDurationSec`, `maxDurationSec`) dan apakah durasi keluaran diambil dari video referensi. |
| `capabilities.modes` / `versions` | Khusus audio: pola penulisan lagu dan versi mesin. |

Kunci yang tidak ada berarti parameter tersebut diabaikan server — tidak error, tidak berpengaruh.

## Parameter yang dimengerti API

Hanya kunci berikut yang dibaca dari objek `parameters`:

| Kunci | Berlaku untuk | Catatan |
| --- | --- | --- |
| `duration` | Video | Boleh ditulis `"5"` atau `"5s"`; akhiran `s` dibuang. |
| `resolution` | Video, Gambar | Tervalidasi terhadap `capabilities.resolutions`. |
| `ratio` | Video, Gambar | Alias `aspect_ratio` juga diterima. |
| `quality` | Gambar | Hanya jika model punya `qualities`. Ikut menentukan harga. |
| `background` | Gambar | Hanya jika model punya `backgrounds`. |
| `output_format` (atau `format`) | Gambar, Audio | Hanya jika model punya `outputFormats`. |
| `negative_prompt` | Sebagian model | Hanya jika `supportsNegativePrompt`. |
| `seed` | Sebagian model | Hanya jika `supportsSeed`. |
| `orientation` | Motion control saja | `image` atau `video`. |

Kunci lain yang kamu kirim (misalnya `style`, `title`, `camera`) **tidak** diproses dan tidak disimpan sebagai error. Validasi dilakukan sebelum job dibuat, jadi typo pada `parameters` berakibat diam-diam: nilai bawaan yang dipakai.

<Note>
  Kalau kamu butuh parameter yang belum ada, kirim permintaan lewat dukungan. Menambah kunci baru tidak akan merusak integrasi lama.
</Note>

### Mode masukan yang dilayani model video

Vidgen menurunkan mode dari referensi yang kamu kirim — kamu tidak menulis `mode` di body. Urutannya:

| Referensi yang dikirim | Mode yang dijalankan |
| --- | --- |
| Tidak ada | Text-to-video |
| Gambar saja | Image-to-video (satu gambar = animasi gambar; beberapa gambar = rangkaian) |
| Video + gambar | Reference-to-video: video sebagai sumber gerakan, gambar sebagai identitas karakter |
| Video saja | Ditolak pada keluarga Gemini Omni; model lain memperlakukannya sebagai video referensi |

`gemini-omni-1.2-unlimited` punya batas yang lebih ketat dari tabel umum: ia menerima satu sampai tiga gambar (I2I), atau satu video **bersama** satu gambar (R2V). Video tanpa gambar pasangan ditolak.

## Model Unlimited

Model andalan paket Unlimited adalah **Gemini Omni 1.2 Flash** (`gemini-omni-1.2-unlimited`). Model ini `unlimitedOnly: true` dan `creditsDefault: 0`.

```json theme={null}
{
  "id": "gemini-omni-1.2-unlimited",
  "label": "Gemini Omni 1.2 Flash (Unlimited)",
  "creditsDefault": 0,
  "unlimitedOnly": true,
  "priceMatrix": {},
  "capabilities": {
    "durations": ["15"],
    "resolutions": ["720p", "1080p"],
    "ratios": ["16:9", "9:16", "1:1"],
    "maxReferenceImages": 3,
    "maxReferenceVideos": 1,
    "maxReferenceAudios": 0,
    "feature": "create"
  }
}
```

Aturannya:

- Akun **tanpa** paket Unlimited aktif yang memanggil id ini dijawab `403`, bukan `402`. Kredit tidak terpotong.
- Akun **dengan** paket aktif membayar 0 kredit, dari dashboard maupun dari API key.
- Model ini tetap tunduk pada batas 2 proses bersamaan dan 50 video sukses per hari. Baca [Konkurensi & batas pemakaian](/concepts/concurrency-limits).
- `gemini-omni-1.2-unlimited` memakai antrean 1-20 di Vidgen: pengguna boleh mengantre sampai 20 job, tetapi server mengirimnya satu per satu ke generator.

### Watermark dihapus otomatis

Hasil `gemini-omni-1.2-unlimited` **tidak pernah terbit dalam keadaan berwatermark**. Sebelum job berubah menjadi `succeeded`, Vidgen menghapus watermark sparkle Gemini dari berkas video:

- Tidak ada biaya kredit tambahan; `creditsCharged` tetap `0` untuk kuota Unlimited.
- Tidak ada parameter khusus di body. `watermark` tetap tidak dibaca, sama seperti field lain di luar skema.
- Proses ini menambah waktu penyelesaian sekitar 1–3 menit. Sistem mencoba sekali lagi bila pembersihan gagal sementara, jadi total bisa lebih lama. Batas atas job tetap 2 jam.
- Bila pembersihan tetap gagal setelah percobaan ulang (jarang), video asli diterbitkan dan job tetap `succeeded`.
- URL hasil yang kamu terima adalah berkas bersih; tidak ada URL terpisah untuk versi berwatermark.

```json 403 theme={null}
{
  "error": "Model \"Gemini Omni 1.2 Flash (Unlimited)\" hanya tersedia untuk paket Unlimited aktif."
}
```

<Warning>
  Jangan menyaring model Unlimited hanya dari `creditsDefault === 0`. Pakai `unlimitedOnly`. Model promosi lain bisa berharga nol sementara tanpa memerlukan langganan.
</Warning>

### Contoh request gambar lengkap

```bash theme={null}
curl -X POST https://vidgen.id/api/v1/generate \
  -H "Authorization: Bearer vg_KEY_KAMU" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.6-sunburst",
    "prompt": "foto produk sepatu kulit di atas meja marmer, cahaya jendela dari kiri",
    "parameters": {
      "resolution": "2K",
      "ratio": "4:5",
      "quality": "high",
      "background": "opaque",
      "output_format": "webp"
    },
    "references": [
      { "url": "https://cdn.tokokamu.com/sepatu-1.png", "type": "image" },
      { "url": "https://cdn.tokokamu.com/sepatu-2.png", "type": "image" }
    ],
    "idempotencyKey": "sku-8841-front-webp"
  }'
```

Tagihan request itu `high:2K` = **4 kredit**, bukan `creditsDefault` 1. Referensi tidak menambah biaya saat ini.

## Urutan pencarian harga

Server meniru urutan ini persis. Tiru di sisi kamu kalau ingin menampilkan perkiraan biaya sebelum mengirim:

```text theme={null}
quality:resolution  →  resolution:duration  →  duration  →  resolution  →  creditsDefault
```

Kunci durasi dicoba dalam beberapa ejaan (`"15"`, `"15s"`) dan kunci kombinasi dicoba dalam dua urutan (`"720p:15"` dan `"15:720p"`), jadi kamu tidak perlu menormalkan sendiri. Surcharge referensi saat ini **0** untuk semua jenis dan jumlah referensi.

## Pencocokan id

`model` dicocokkan dengan kolom id di katalog, dan ejaan dengan titik serta tanda hubung diperlakukan sama:

```text theme={null}
kling-mc-3-0  ==  kling.mc.3.0
```

Beberapa id punya alias internal. Rekomendasinya tetap: pakai `id` apa adanya dari respons `GET /api/v1/models`.

Model yang sedang dimatikan **tetap ada** di database supaya riwayat lama punya label, tapi tidak muncul di katalog dan tidak bisa dijalankan. Permintaan ke model nonaktif dijawab `409`.

<Note>
  Dua model bisa punya nama tampilan yang mirip tetapi id, harga, dan kapabilitas berbeda — misalnya `gemini-omni-flash-1-1` (berbayar, 7 gambar referensi) dan `gemini-omni-1.2-unlimited` (kuota Unlimited, 3 gambar, 1 video referensi). Selalu pilih berdasarkan `id`, jangan berdasarkan `label`.
</Note>

## Model motion control

Model dengan `capabilities.feature: "motion"` punya aturan sendiri:

- `prompt` boleh kosong — gerakannya datang dari video referensi.
- `parameters.duration` **diabaikan**. Server mengukur panjang video referensi, membulatkannya ke atas, lalu memakai angka itu sebagai durasi keluaran.
- `parameters.orientation` memilih apakah rasio keluaran mengikuti gambar karakter (`image`) atau video gerakan (`video`).
- Batas durasi referensi lebih longgar daripada model biasa: 3–30 detik, dan video tidak dipotong otomatis. Lihat [Media referensi](/concepts/reference-media).

Dua model aktif di kelompok ini: `kling-mc-3-0` (durasi dari video) dan `vg-motion` (durasi dipilih, 15 detik). `capabilities.feature` dan `capabilities.motion` ikut dikirim di katalog, jadi kamu bisa memfilter secara programatik:

```js theme={null}
const motionModels = models.video.filter((m) => m.capabilities.feature === "motion");

for (const m of motionModels) {
  const range = m.capabilities.motion; // { minDurationSec: 3, maxDurationSec: 30 }
  console.log(m.id, range?.minDurationSec, range?.maxDurationSec);
}
```

Sebagian model motion menambahkan `durationFromReference` di objek itu. Bila kuncinya tidak ada, perlakukan durasi sebagai berasal dari video referensi — itu perilaku bawaan kelompok motion.
