Model Vidgen dikelola dari server dan bisa berubah kapan saja — model baru masuk, model lama dipensiunkan, harga kredit disesuaikan. Karena itu **jangan hardcode daftar model** di produkmu. Ambil dari runtime:

```bash theme={null}
curl https://vidgen.id/api/v1/models
```

Endpoint ini publik (tanpa API key) dan mengembalikan tiga keranjang: `video`, `image`, `audio`. Hanya model aktif yang muncul.

## Bentuk satu entri

```json theme={null}
{
  "id": "seedance-2-5-flash",
  "label": "Seedance 2.5 Flash",
  "category": "Video",
  "mode": "video",
  "creditsDefault": 3,
  "priceMatrix": { "20": 3 },
  "capabilities": {
    "durations": ["20"],
    "ratios": ["16:9", "9:16"],
    "resolutions": ["720p"],
    "maxReferenceImages": 0,
    "maxReferenceVideos": 0,
    "maxReferenceAudios": 0
  }
}
```

| Field | Arti |
| --- | --- |
| `id` | Nilai yang kamu kirim di body `model`. |
| `label` | Nama tampilan. Bisa berubah; jangan jadikan kunci logika. |
| `category` | `Video` \| `Image` \| `Audio`. |
| `mode` | Sama dengan `category` tapi huruf kecil; dipakai untuk memilih tab parameter. |
| `creditsDefault` | Harga dasar dalam kredit bila tidak ada override yang cocok. |
| `priceMatrix` | Override per kunci: `"15"`, `"720p"`, `"720p:15"`, atau `"low:2K"` (kualitas:resolusi). |
| `capabilities.durations` | Nilai valid untuk `parameters.duration`. |
| `capabilities.ratios` | Nilai valid untuk `parameters.ratio`. `auto` selalu diterima dan tidak divalidasi. |
| `capabilities.resolutions` | Nilai valid untuk `parameters.resolution`. |
| `capabilities.maxReferenceImages` / `Videos` / `Audios` | Berapa banyak referensi jenis itu yang boleh dikirim. |
| `capabilities.minReferenceVideos` | Jumlah video referensi MINIMUM. Kalau ada, permintaan tanpa video dijawab `400` sebelum kredit terpotong. |

Beberapa model juga mengembalikan `qualities`, `backgrounds`, `outputFormats`, `supportsNegativePrompt`, atau `supportsSeed`. Kalau kuncinya tidak ada, parameter tersebut diabaikan server — tidak error, tidak berpengaruh.

## Parameter yang dimengerti API

Hanya kunci berikut yang dibaca dari objek `parameters`:

| Kunci | Berlaku untuk | Catatan |
| --- | --- | --- |
| `duration` | Video | Boleh ditulis `"5"` atau `"5s"`; akhiran `s` dibuang. |
| `resolution` | Video, Gambar | Tervalidasi terhadap `capabilities.resolutions`. |
| `ratio` | Video, Gambar | Alias `aspect_ratio` juga diterima. |
| `quality` | Gambar | Hanya jika model punya `qualities`. |
| `background` | Gambar | Hanya jika model punya `backgrounds`. |
| `output_format` (atau `format`) | Gambar, Audio | Hanya jika model punya `outputFormats`. |
| `negative_prompt` | Sebagian model | Hanya jika `supportsNegativePrompt`. |
| `seed` | Sebagian model | Hanya jika `supportsSeed`. |
| `orientation` | Motion control saja | `image` atau `video`. |

Kunci lain yang kamu kirim (misalnya `style`, `title`, `camera`) **tidak** diproses dan tidak disimpan sebagai error. Validasi dilakukan sebelum job dibuat, jadi typo pada `parameters` diam-diam.

<Note>
  Kalau kamu butuh parameter yang belum ada, kirim permintaan lewat dukungan. Menambah kunci baru tidak akan merusak integrasi lama.
</Note>

## Batas ketat per model

Sebagian model hanya menerima sejumlah nilai tertentu. `capabilities` di katalog adalah sumber kebenarannya, tapi tabel berikut adalah batas yang paling sering salah dikirim. Nilai di luar daftar tidak divalidasi oleh API kami sebelum job dibuat — permintaan diteruskan ke generator, job berakhir gagal, dan kredit dikembalikan penuh.

| Model (`id`) | Kategori | Durasi | Resolusi | Referensi |
| --- | --- | --- | --- | --- |
| `muse-video` | Video | `10` `20` `30` `40` `50` `60` detik | hanya `720p` | 4 gambar |
| `minimax-h3` | Video | `5` `10` `15` detik | hanya `2K` | 9 gambar, 3 video, 3 audio |
| `gemini-omni-flash-1-1` | Video | `10` detik saja | `720p`, `1080p` | 7 gambar |
| `kling-4.0` | Video | `5` `10` `15` `30` detik | `720p`, `1080p` | 10 gambar |
| `gpt-image-2.6-sunburst`, `gpt-image-2.6-flare` | Image | — | `1K`, `2K`, `4K` | 16 gambar |
| `gpt-image-2.5-sunburst`, `gpt-image-2.5-flare` | Image | — | `1K`, `2K`, `4K` | lihat katalog |
| `nano-banana-2-lite` | Image | — | hanya `1K` | 14 gambar |
| `nano-banana-2`, `nano-banana-2.1` | Image | — | `512px`…`4K` | 14 gambar |
| `nano-banana-pro` | Image | — | `1K`, `2K`, `4K` | 14 gambar |
| `seedream-5.0-lite` | Image | — | `2K`, `3K` | 10 gambar |
| `seedream-5.0-flash`, `seedream-5.0-pro` | Image | — | `1K`, `1.5K`, `2K` | 10 gambar |
| `wan2.7-image-spicy` | Image | — | `1K`, `2K` | 9 gambar |
| `wan2.7-image-pro-spicy` | Image | — | `1K`, `2K`, `4K` | 9 gambar |

Dua hal yang perlu diperhatikan di atas angka-angka itu:

- **Kualitas mengubah harga pada model gambar.** Pada `gpt-image-2.6-*`, `quality` ikut menentukan harga lewat kunci `"low:1K"` … `"max:4K"` di `priceMatrix`. Tagihan bisa berbeda belasan kali pada resolusi yang sama, jadi jangan berasumsi `creditsDefault` adalah harga tertinggimu.
- **Rasio itu terbatas, bukan bebas.** `muse-video` dan `minimax-h3` punya daftar rasio sendiri; `gemini-omni-flash-1-1` hanya `16:9` dan `9:16`. `auto` selalu diterima dan tidak divalidasi.

## Pencocokan id

`model` dicocokkan dengan kolom id di katalog, dan ejaan dengan titik serta tanda hubung diperlakukan sama:

```text theme={null}
seedance-2-5-flash  ==  seedance.2.5.flash
```

Beberapa id punya alias internal (misalnya `vidgen-1.0`). Rekomendasinya tetap: pakai `id` apa adanya dari respons `GET /api/v1/models`.

Model yang sedang dimatikan **tetap ada** di database supaya riwayat lama punya label, tapi tidak muncul di katalog dan tidak bisa dijalankan. Permintaan ke model nonaktif dijawab `409`.

## Model motion control

Model dengan kemampuan transfer gerakan punya aturan sendiri, dan ada dua perilaku durasi yang berbeda:

- `prompt` boleh kosong — gerakannya datang dari video referensi.
- **Kling Motion Control** (`kling-mc-3-0`, `kling-mc-3-0-pro`): panjang video referensi menentukan durasi (dan harga) keluaran, bukan angka yang kamu kirim di `parameters.duration`.
- **Vidgen Motion** (`vg-motion`): durasi diambil dari `parameters.duration` (katalog saat ini hanya 15 detik), dan harga ikut `resolution` (`720p` / `480p`). Video referensi yang lebih panjang dari durasi otomatis dipotong di server.
- Batas durasi referensi lebih longgar daripada model biasa; lihat [Media referensi](/concepts/reference-media).

<Note>
  Atribut `capabilities.motion` tidak muncul di `GET /api/v1/models` — yang dikirim hanya `durations`, `ratios`, `resolutions`, dan batas jumlah referensi. Jadi dari API punanya, perilaku "durasi dari video" harus diketahui dari id modelnya, bukan dari katalog. Kalau kamu perlu memfilter secara programatik, tanyakan lewat dukungan sebelum hardcode daftar id.
</Note>

## Audio

Katalog menyertakan keranjang `audio`, tapi generate audio lewat API key **belum dibuka**. Kirim `mode: "audio"` hari ini akan membuat job yang gagal di tengah jalan dengan pengembalian kredit. Generate audio masih lewat dashboard.
