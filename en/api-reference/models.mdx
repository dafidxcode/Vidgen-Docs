Returns the models that are currently usable, grouped into `video`, `image`, and `audio`. Disabled models are not returned.

<Info>
  This endpoint **does not require an API key** because it only holds the public catalog. The other pages in this tab still need a key.
</Info>

<RequestExample>

```bash cURL theme={null}
curl https://vidgen.id/api/v1/models
```

```js Node.js theme={null}
const models = await (await fetch("https://vidgen.id/api/v1/models")).json();

const video = models.models.video.find((m) => m.capabilities.durations.includes("30"));
console.log(video?.id, video?.creditsDefault, video?.priceMatrix);
```

```python Python theme={null}
models = requests.get("https://vidgen.id/api/v1/models").json()["models"]

for m in models["video"]:
    print(m["id"], m["capabilities"]["durations"], m["creditsDefault"])
```

</RequestExample>

### Responses

<ResponseField name="success" type="boolean" required>
  `true` when the catalog loaded successfully.
</ResponseField>

<ResponseField name="models" type="object" required>
  Three buckets: `video`, `image`, `audio`. Each one is an array of model objects.

  <Expandable title="one model entry" defaultOpen>
    <ResponseField name="id" type="string" required>
      The value for the `model` field when generating.
    </ResponseField>
    <ResponseField name="label" type="string">
      Display name. It can change; do not use it as a logic key.
    </ResponseField>
    <ResponseField name="category" type="string">
      `"Video"`, `"Image"`, or `"Audio"`.
    </ResponseField>
    <ResponseField name="mode" type="string">
      `video`, `image`, or `audio`.
    </ResponseField>
    <ResponseField name="creditsDefault" type="number" required>
      Base price in credits when no override matches. Can be fractional.
    </ResponseField>
    <ResponseField name="unlimitedOnly" type="boolean" required>
      `true` when the model is only available to accounts with an active Unlimited plan. Calling it without a subscription is answered `403`, not `402`. Do not filter subscription models by `creditsDefault === 0` — use this flag.
    </ResponseField>
    <ResponseField name="priceMatrix" type="object">
      Price overrides. Possible keys: duration (`"15"`), resolution (`"720p"`), combination (`"720p:15"`), or quality:resolution (`"low:2K"`).
    </ResponseField>
    <ResponseField name="capabilities" type="object">
      Validation rules for this model's parameters.

      <Expandable title="contents of capabilities">
        <ResponseField name="durations" type="array<string>">
          Valid values for `parameters.duration`.
        </ResponseField>
        <ResponseField name="ratios" type="array<string>">
          Valid values for `parameters.ratio`. `auto` is always accepted and is not validated.
        </ResponseField>
        <ResponseField name="resolutions" type="array<string>">
          Valid values for `parameters.resolution`.
        </ResponseField>
        <ResponseField name="maxReferenceImages" type="number">
          Reference image limit.
        </ResponseField>
        <ResponseField name="maxReferenceVideos" type="number">
          Reference video limit.
        </ResponseField>
        <ResponseField name="maxReferenceAudios" type="number">
          Reference audio limit.
        </ResponseField>
        <ResponseField name="minReferenceVideos" type="number">
          Minimum reference video count. Only emitted when greater than 0; a request without a video is answered `400` before any credit is deducted.
        </ResponseField>
        <ResponseField name="qualities" type="array<string>">
          Valid values for `parameters.quality`. Only emitted on models that support it, and it also drives the price through the `quality:resolution` key.
        </ResponseField>
        <ResponseField name="backgrounds" type="array<string>">
          Valid values for `parameters.background`, e.g. `auto`, `opaque`, `transparent`.
        </ResponseField>
        <ResponseField name="outputFormats" type="array<string>">
          Valid values for `parameters.output_format`, e.g. `png`, `jpeg`, `webp`.
        </ResponseField>
        <ResponseField name="supportsNegativePrompt" type="boolean">
          Only emitted when `true`. Means `parameters.negative_prompt` is forwarded to the generator.
        </ResponseField>
        <ResponseField name="supportsSeed" type="boolean">
          Only emitted when `true`. Means `parameters.seed` is forwarded to the generator.
        </ResponseField>
        <ResponseField name="feature" type="string">
          `"create"` or `"motion"`. Motion models take their duration from the reference video and ignore `parameters.duration`.
        </ResponseField>
        <ResponseField name="motion" type="object">
          Motion models only: `minDurationSec`, `maxDurationSec`, and sometimes `durationFromReference`.
        </ResponseField>
        <ResponseField name="modes" type="array<string>">
          Audio only: songwriting mode, e.g. `custom`, `simple`, `cover`.
        </ResponseField>
        <ResponseField name="versions" type="array<string>">
          Audio only: selectable engine versions.
        </ResponseField>
      </Expandable>

      Optional keys are only emitted when the model actually has them. A missing key means that parameter is ignored by the server — no error, no effect.
    </ResponseField>
  </Expandable>
</ResponseField>

## How to use it in your product

<AccordionGroup>
  <Accordion title="Cache it, do not hardcode">
    Fetch the catalog once when your service starts, keep it for 5–15 minutes, and refresh it when you receive a `409` (`model ... sedang tidak tersedia`). The model list changes without announcement.
  </Accordion>
  <Accordion title="Build your UI from capabilities">
    Hide options that are not in the selected model's capabilities: `durations`, `ratios`, `resolutions`, then `qualities`, `backgrounds`, and `outputFormats` when those keys exist. Show an image uploader only when `maxReferenceImages > 0`, and so on for video and audio. Validating on your side avoids requests the server would certainly reject.
  </Accordion>
  <Accordion title="Estimate the cost">
    Mirror the server's price lookup order: `quality:resolution` → `resolution:duration` → `duration` → `resolution` → `creditsDefault`. Some models only fill part of the combinations (sparse matrix); a missing key falls through to the next level, not to an error. References add no cost.
  </Accordion>
  <Accordion title="Unlimited models are not free models">
    `unlimitedOnly: true` means the model is only for accounts with an active Unlimited plan. Its `creditsDefault` is `0` because the charge comes out of the quota, not because it is free for everyone. Without a subscription, `POST /api/v1/generate` answers `403` with `code: "unlimited_required"` before any credit is touched. To show the right choices to ordinary users, filter `models.video.filter((m) => !m.unlimitedOnly)`.
  </Accordion>
  <Accordion title="Gemini Omni 1.2 Flash (Unlimited)">
    The Unlimited plan's flagship model: `gemini-omni-1.2-unlimited` accepts 1-3 images (I2I) or 1 image + 1 video (ref-to-video) at duration `15`, resolution `720p`/`1080p`. Read `maxReferenceImages`, `maxReferenceVideos`, and `durations` from the catalog; do not hardcode them. Its queue holds 1-20 jobs on the Vidgen side and forwards them one at a time. See [Concurrency & usage limits](/en/concepts/concurrency-limits).

    The Gemini sparkle watermark is removed automatically before the job becomes `succeeded`: no extra credit charge, no special parameter, and roughly 1–3 minutes of added processing time (with one retry if cleaning fails transiently). The result URL always points to the clean file.
  </Accordion>
  <Accordion title="Audio appears in the catalog but cannot be generated yet">
    The `audio` bucket holds `suno-v6` and `suno-cover-v6`. Sending them through an API key is not open yet, so present them as "dashboard only". The `modes` and `versions` keys are published for future integration, not as a sign the endpoint is live.
  </Accordion>
</AccordionGroup>
