The Vidgen API is the HTTP interface for the Vidgen video and image generation engine. With one API key you can create jobs, send reference images or video, and fetch the finished result — without opening the dashboard.

## How it works

The Vidgen API is **asynchronous**. A `POST /api/v1/generate` request is answered immediately with `202 Accepted` containing `job.id`, and you then fetch the result with `GET /api/v1/jobs/{id}` until the status is `succeeded`.

<Steps>
  <Step title="Send a prompt + model">
    Pick a model from the catalog (for example `wan-3.0`), write your prompt, and set duration/ratio/resolution in `parameters`.
  </Step>
  <Step title="The server queues the job">
    Credits are deducted up front, the job enters the queue, and you receive `job.id` along with your queue position.
  </Step>
  <Step title="Poll until it finishes">
    Check the status every 5 seconds. While the status is `queued` you see `queuePosition`; when it is `succeeded` you get the media URL.
  </Step>
  <Step title="Download the result">
    Store the URL in your own storage. Result links have a limited lifetime, so do not rely on them as a permanent source.
  </Step>
</Steps>

## Get started in 3 steps

<Steps>
  <Step title="Create an API key">
    Sign in at [vidgen.id → Account](https://vidgen.id/account#api-keys), click **Create key**, and copy the value. Keys are formatted `vg_...` and are shown only once.
  </Step>
  <Step title="Send your first request">

```bash create curl
curl -X POST https://vidgen.id/api/v1/generate \
  -H "Authorization: Bearer vg_GANTI_DENGAN_KEY_KAMU" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan-3.0",
    "prompt": "Kopi susu di meja kayu, cahaya pagi menembus jendela, kamera bergerak pelan ke kanan",
    "parameters": { "duration": "5", "ratio": "16:9", "resolution": "720p" }
  }'
```

  </Step>
  <Step title="Fetch the result">

```bash poll curl
curl https://vidgen.id/api/v1/jobs/JOB_ID \
  -H "Authorization: Bearer vg_GANTI_DENGAN_KEY_KAMU"
```

  </Step>
</Steps>
