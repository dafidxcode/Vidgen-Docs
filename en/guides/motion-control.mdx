Motion control takes the **motion** from a video and applies it to the **character** in your image. The result is a new video: face and style from the image, motion from the video.

Vidgen has two motion-transfer engines and **their rules differ**. Read the table before you pick a `model`.

| Aspect | `kling-mc-3-0` / `kling-mc-3-0-pro` | `vg-motion` (Vidgen Motion) |
| --- | --- | --- |
| Output duration | Borrowed from the reference video's length, re-measured on the server | **Chosen** by you; this model only offers 15 seconds |
| Price | Per second, from the measured reference video length | Fixed per duration + resolution combination (`15s` at `480p` or `720p`) |
| Resolution | 720p | 480p (cheaper) or 720p |
| Ratio | Follows the image or the video through `parameters.orientation` | `parameters.ratio` like any regular video model (`16:9` / `9:16`) |
| Required references | Exactly 1 character image + 1 motion video | At least 1 motion video; up to 10 images and 5 videos |
| `prompt` length | Maximum 2,500 characters | Same rules as the other video models |
| `parameters.duration` | Ignored | Honored, and must appear in `capabilities.durations` |

These numbers are not written by hand: they come from `GET /api/v1/models`. Motion models are marked `capabilities.feature === "motion"`, and `capabilities.motion.durationFromReference` tells you where the duration comes from — `true` (Kling) means the video decides the length, `false` (Vidgen Motion) means you do.

## The three-file flow

<Steps>
  <Step title="Upload the motion video">
    Include the target model id so the server applies the correct duration rules and does not trim the video.

```bash theme={null}
curl -X POST https://vidgen.id/api/v1/upload \
  -H "Authorization: Bearer vg_YOUR_KEY" \
  -F "file=@movement.mp4" \
  -F "model=kling-mc-3-0-pro"
```
  </Step>
  <Step title="Upload the character image">
    The photo or illustration you want to animate. A front-facing face gives the most stable results.
  </Step>
  <Step title="Send a job with typed references">
    The order does not determine the role — the `type` field is what tells them apart.

```json theme={null}
{
  "model": "kling-mc-3-0-pro",
  "prompt": "",
  "references": [
    { "id": "ref_api_1762261900_movement.mp4", "type": "video", "url": "/api/media/..." },
    { "id": "ref_api_1762261901_character.png", "type": "image", "url": "/api/media/..." }
  ],
  "parameters": { "orientation": "video" }
}
```

    For `vg-motion`, replace `parameters.orientation` with `duration`, `resolution` and `ratio`, exactly like the other video models:

```json theme={null}
{
  "model": "vg-motion",
  "prompt": "",
  "references": [
    { "id": "ref_api_1762261900_movement.mp4", "type": "video", "url": "/api/media/..." },
    { "id": "ref_api_1762261901_character.png", "type": "image", "url": "/api/media/..." }
  ],
  "parameters": { "duration": "15", "resolution": "480p", "ratio": "9:16" }
}
```
  </Step>
</Steps>

## Kling Motion Control rules

| Aspect | Kling motion control |
| --- | --- |
| `prompt` | May be empty. If you leave it empty, the server fills in a neutral instruction automatically. |
| `parameters.duration` | Ignored. Output duration = length of the reference video, re-measured on the server. |
| Price | Follows the measured duration of the reference video, not the number you send. |
| Reference video range | 3–30 seconds, narrowed per model through the catalog when a machine supports less. |
| `orientation: "image"` | The reference video is trimmed to a maximum of 10 seconds. |
| `prompt` length | Maximum 2,500 characters. Anything longer is rejected before credits are deducted. |

`parameters.orientation` only applies to this model:

- `"image"` — the output ratio follows the character image.
- `"video"` — the output ratio follows the motion video.

Any other value (or this key sent to a non-motion model) is ignored without an error.

## Reference video format

Export **MP4** when you can. WebM is not rejected outright: for motion models the server converts it to MP4 first so the duration can be read. That conversion runs ffmpeg on the server, so a WebM that fails to convert (broken file, a stream with no length metadata) still ends here:

<Warning>
  `Durasi video referensi tidak bisa dibaca.` (API errors come back in Indonesian.) Transcode it yourself and upload again:

```bash theme={null}
ffmpeg -i broken.webm -c:v libx264 -preset veryfast -crf 20 -movflags +faststart out.mp4
```
</Warning>

## Why Kling will not let you set the duration

Kling motion control billing is calculated from the length of the motion video that was actually processed. If the server trusted the client's `duration` value, a 30-second video could be billed as 3 seconds. That is why the duration is re-measured from the stored file and the value you send is overwritten.

In practice: if you need a 6-second output, cut the reference video to 6 seconds before uploading it. `vg-motion` does not work that way — you pick the duration and resolution, and the length of your reference video does not change the price.

## Check-list before you send

<AccordionGroup>
  <Accordion title="Motion video">
    Kling: one file only. Vidgen Motion: at least one, up to five. Motion clearly visible, subject stays inside the frame, stable lighting, no text burned into the picture.
  </Accordion>
  <Accordion title="Character image">
    Minimum resolution of 300 px on the shortest side, front-facing face, not covered by objects, style consistent with what you want in the final result. Kling accepts exactly one image; Vidgen Motion accepts up to ten.
  </Accordion>
  <Accordion title="Cost">
    Check first: `GET /api/v1/user/credits` for the balance. On Kling the reference video's duration determines the bill, so a longer video means more credits. On Vidgen Motion the price comes from `duration` + `resolution` in `priceMatrix`.
  </Accordion>
</AccordionGroup>

<Tip>
  Motion control models can be disabled at any time. If you receive a `409`, do not try other spellings — refetch `GET /api/v1/models` and move the request to an available model.
</Tip>
