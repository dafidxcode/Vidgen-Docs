Vigen API adalah antarmuka HTTP untuk mesin generate video dan gambar Vigen. Dengan satu API key kamu bisa membuat job, mengirim gambar atau video referensi, lalu mengambil hasil jadi — tanpa perlu membuka dashboard.

## Cara kerjanya

Vigen API bersifat **asinkron**. Sebuah request `POST /api/v1/generate` langsung dijawab `202 Accepted` berisi `job.id`, lalu hasilnya diambil dengan `GET /api/v1/jobs/{id}` sampai statusnya `succeeded`.

<Steps>
  <Step title="Kirim prompt + model">
    Pilih model dari katalog (contoh: `seedance-2-5-flash`), tulis prompt, atur durasi/rasio/resolusi lewat `parameters`.
  </Step>
  <Step title="Server memasukkan antrean">
    Kredit dipotong di awal, job masuk antrean, dan kamu menerima `job.id` beserta posisi antrean.
  </Step>
  <Step title="Polling sampai selesai">
    Cek status tiap 5 detik. Selama status `queued` kamu melihat `queuePosition`; saat `succeeded` kamu mendapat URL media.
  </Step>
  <Step title="Unduh hasilnya">
    Simpan URL-nya ke storage kamu sendiri. Tautan hasil punya masa berlaku terbatas, jadi jangan bergantung padanya sebagai sumber permanen.
  </Step>
</Steps>

## Mulai dalam 3 langkah

<Steps>
  <Step title="Buat API key">
    Masuk ke [vigen.id → Akun](https://vigen.id/account#api-keys), klik **Buat kunci**, lalu salin nilainya. Key berformat `vg_...` dan hanya ditampilkan satu kali.
  </Step>
  <Step title="Kirim permintaan pertama">

```bash create curl
curl -X POST https://vigen.id/api/v1/generate \
  -H "Authorization: Bearer vg_GANTI_DENGAN_KEY_KAMU" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-5-flash",
    "prompt": "Kopi susu di meja kayu, cahaya pagi menembus jendela, kamera bergerak pelan ke kanan",
    "parameters": { "duration": "5", "ratio": "16:9", "resolution": "720p" }
  }'
```

  </Step>
  <Step title="Ambil hasilnya">

```bash poll curl
curl https://vigen.id/api/v1/jobs/JOB_ID \
  -H "Authorization: Bearer vg_GANTI_DENGAN_KEY_KAMU"
```

  </Step>
</Steps>
